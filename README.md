# LOTR Converter

A small SwiftUI app that converts currencies in the style of Lord of the Rings.  
Built with Swift 6.

## What it does
- Convert between Copper Penny, Silver Penny, Silver Piece, Gold Penny, and Gold Piece.
- Change currencies by tapping either side and selecting from a grid.
- Shows an info screen with the exchange rates.
- Saves the last used currencies using UserDefaults.
- Uses TipKit to give small in-app tips.

## Tech used
- Swift 6 / SwiftUI
- UserDefaults
- TipKit
- Custom SwiftUI views (CurrencyIcon, IconGrid, ExchangeRate)
